# AXIOM

Нишевый статический портал новостей об ИИ-технологиях.

- Стек: [Astro](https://astro.build) (static)
- Деплой: GitHub Pages (`/axiom`)
- Язык интерфейса: русский

## Локально

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

Контент: `src/content/articles`, `src/content/authors`. Админ-панели нет.
